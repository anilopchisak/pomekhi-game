## Executable guarantees

The configuration owns real command arrays. Unit tests protect startup validation. Integration tests use actual HTTP, independent sockets and built client assets. Documentation checks validate English text, file links and unfinished adaptation markers. Graph evaluation verifies real source routes; it is not an application test or an exhaustive call-graph guarantee.

The requirements pin and supplied graph publication workflow are preserved. The agent.py command runner additionally owns process-tree cleanup on timeout and interruption, with a real npm-descendant regression. The bridge adds a tested import-boundary resolver: external package/asset references are labeled explicitly, compiled .js specifiers resolve to indexed TypeScript files, and direct named re-exports resolve through AST evidence to unique definitions. Missing internal imports, unsupported bindings and unknown call endpoints still block publication. The actual adapted copy has regression tests in tests/agentkit. No Git initialization, commit, push, CI registration, public deployment or external game account creation is part of setup.

## Remaining external acceptance

Windows launchers, actual mobile browsers and ngrok/carrier access need the matching environments. The task bank, gameplay, audio, editor, authorization and game-state recovery remain product implementation work. Those limits must remain visible even when foundation checks pass.
