# Future card-set integration

Status: proposal only. The current task delivers content, not any of the mechanisms below. Existing sessions and the editable local catalog have not been migrated or changed.

The domestic-horror authoring revision is complete independently of these future mechanisms. Its 12-work fiction registry, 185-record decision register and actor/causal annotations are private author data. Do not expose those explanations as assistance to searching players, use a fictional narrative as sensor evidence or bind random assignments to a particular opening story.

The latest user instruction excludes all task props, including pre-positioned items. Only the phone is required equipment; bodies, voices and naturally available space provide actions. Existing house mirrors are explicitly permitted scenery for the angel and reflection scene. The Dwelling is an agreed empty place. The authoring amendment register records superseded material conditions; no inventory system or application behavior is added.

## 1. Adopt the authored content contract

- Introduce a versioned no-helper card contract. Remove the mandatory clue field from new possessed records and from the new player/editor presentation; do not insert empty or concealed replacement helpers.
- Keep issued legacy cards as frozen private assignment data until the original session ends or an explicit migration handles them. Do not silently reinterpret a live assignment by ID lookup in the new bank.
- Keep stable editorial IDs separate from existing runtime p/e IDs. Use provenance as author metadata, not public player data.
- Add the original optional-subset selection and per-card prerequisites. Ordinary cards have no optional labels. Retire numbered progression for original-rule play; it is not a mapping to the harder subset.
- Extend authoring/import/export beyond personal possessed/exorcist cards before offering a full-set import. The pomekhi.editorial-card-set format deliberately cannot pass as the current pomekhi.cards v1 format.

## 2. Complete original-rule mechanics

- Preserve unresolved groups, assignments and physical locations across checks and restart. Alternate dealing only among free returners, starting with exorcist, including a single returning rescuer.
- Add an agreed empty Dwelling place, three private digital starting mission records and explicit reports of each card's on-site gesture or phrase. No vessel, marker or physical task object exists. A remote action cannot establish a visit. The phone stays with its owner.
- Add stories, 10 ordinary prophecies and the final door with original candle setup, once-only rescue credit, ineligible captured-exorcist missions and terminal victory/defeat.
- Resolve original candle-penalty ties and exact trial branch timing against a more specific ruling. The editorial walkthrough uses checking-entry prophecy count before new candle movement; this is not asserted as a verified original algorithm.

## 3. Add private computer trials

- Select seven eligible trials and freeze private content/order. Apply venue/subset prerequisites before selection; do not redraw because an outcome becomes inconvenient.
- Deliver only the affected player's instruction. Store hidden objectives, both branches, target identity and evidence privately. The organizer keeps playing as a medium, with no requirement to inspect hidden trial text.
- Capture explicit physical reports, including independent answers for memory tests. Missing packets do not prove silence, fear, capture or non-delivery. Conflicts require review before confirming a score.
- T003 needs a separate in-fiction address report and a private response. T004 needs a private return message and an explicit exception allowing its selected player to carry a remembered fictional address to the table before the global call, then revisit the empty Dwelling place. Neither private reply is a global recall.
- Award at most one additional success per trial. A trial bonus may coexist with failure of the exorcist's original mission; it never restores credit lost through capture.
- Suppress all trial instructions, effects and bonuses in the original first-game variant. Chosen cards only count its seven rounds.

## 4. Verify before rollout

Validate privacy, persistence, delayed reports and restart with the actual shared protocol and independent consumers. Exercise a sole free rescuer, late group release, a captured mission completed before capture, absent trial reports, both trial branches and the final door. Update the owning design and product explanations with those implementation changes.

Then playtest discovery, prop availability, contact agreement, fear and the original candle budget with real participants. Check dim-screen visibility, audibility and mobile interruption on actual supported devices. Keep editorial completion, software checks and live acceptance as distinct claims. No paid runtime AI, account requirement or external service is necessary for this content.
